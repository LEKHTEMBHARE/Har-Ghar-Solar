# ☀️ Har Ghar Solar (PM-Surya Ghar Scheme Portal)

An interactive web platform designed to assist users in understanding, calculating, and applying for the **PM-Surya Ghar: Muft Bijli Yojana**.

## 🚀 Key Features

- **Solar Capacity Calculator:** Estimate recommended plant capacity (kW) based on monthly electricity usage.
- **Subsidy & Savings Breakdown:** Real-time calculation of Central Government subsidies and monthly savings.
- **Eligibility Checker:** Interactive guide to verify rooftop space and DISCOM prerequisites.
- **Application Workflow:** Step-by-step navigation for applying on the National Rooftop Solar Portal.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (or React / Tailwind CSS)
- **Deployment:** Netlify / GitHub Pages
